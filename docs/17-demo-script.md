# 17 – תסריט הדגמה (5 דקות)

## לפני ההדגמה (10 דקות לפני)

1. `bash dev.sh` משורש ה-Repo. מחכים לשורה "הכול עלה" ולדפדפן שנפתח.
2. בודקים ש-`/system` ירוק: Somee, ChromaDB, Ollama.
3. מחממים את המודל כדי שההערכה הראשונה תהיה מהירה: `ollama run qwen2.5:7b-instruct "שלום"` ויוצאים עם `/bye`.
4. פותחים שני חלונות דפדפן: רגיל (משקיעה) ו-Incognito (סוכן). כך אפשר להיות מחוברות לשני התפקידים במקביל.
5. כדי שהסיור יופיע שוב בהדגמה: בדף "עזרה" לוחצים "הצגת סיור ההיכרות".
