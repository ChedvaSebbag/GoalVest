# 12 – אבטחה, פרטיות ורגולציה

## 12.1 אוטנטיקציה

| נושא | החלטה |
|---|---|
| סיסמאות | bcrypt (cost 12). מדיניות: 8+ תווים, אות ומספר |
| טוקנים | JWT (flask-jwt-extended). Access ל-30 דקות עם claims: `sub`, `role`, `institution_id`. Refresh ל-7 ימים |
| אחסון בלקוח | Access בזיכרון (Service), Refresh ב-`localStorage` (פשטות לפרויקט; מתועד כפשרה מול HttpOnly Cookie) |
| פסילה | רשימת `jti` פסולים בטבלה (logout, החלפת סיסמה) |
| ניסיונות כושלים | 5 ניסיונות בחלון של 15 דקות לאימייל → חסימה זמנית (Flask-Limiter) |
| שחזור סיסמה | טוקן אקראי של 32 בתים, נשמר כ-hash, תוקף 30 דקות, חד-פעמי |

## 12.2 הרשאות

- בדיקה בשרת בכל Endpoint: דקורטור `@require_role(...)` + בדיקת בעלות על המשאב בתוך ה-Handler או ה-Query (משקיע רואה רק את שלו, סוכן רק לידים של הגוף שלו).
- Guards באנגולר הם לחוויית משתמש בלבד, לא לאבטחה.
- פרטי קשר של משקיע מוסתרים ב-Query אם אין `consent_share_contact`.

## 12.3 הגנות כלליות

- CORS רק לכתובת ה-Frontend.
- ולידציה עם Pydantic לכל קלט. SQLAlchemy עם פרמטרים (מניעת SQL Injection).
- העלאת קבצים: רק PDF/DOCX, בדיקת MIME ו-Magic Bytes, עד 10MB, שם קובץ חדש (UUID), שמירה מחוץ לתיקיית הקוד.
- Angular מגן מ-XSS כברירת מחדל. אין `innerHTML` עם תוכן מה-LLM. נימוק ה-AI מוצג כטקסט.
- **Prompt Injection**: מסמכים שסוכנים מעלים ותוצאות Web הם תוכן לא אמין. ה-System Prompt מגדיר שתוכן ממקורות הוא מידע ולא הוראות, והולידציה בשלב 7 חוסמת מוצרים שאינם ברשימת המועמדים.
- סודות (`DB_CONNECTION`, `JWT_SECRET`, `TAVILY_API_KEY`, Gmail OAuth) ב-`.env` שנמצא ב-`.gitignore`. ב-Repo רק `.env.example`. GitHub Secret Scanning מופעל.

## 12.4 פרטיות

- מינימום מידע: אין ת"ז, אין פרטי חשבון בנק.
- נתונים אישיים לא נשלחים ל-Tavily. ה-LLM וה-Vector DB מקומיים.
- **Event Sourcing ו"הזכות להישכח"**: אירועים לא נמחקים. לכן PII נשמר באירועים רק ב-`UserRegistered`/`InvestorProfileCreated`, ותוכנן (Could) מנגנון Crypto-Shredding: הצפנת שדות PII במפתח לכל משתמש, ומחיקת המפתח כשמשתמש מבקש מחיקה.

## 12.5 רגולציה והבהרות

- המערכת היא פרויקט אקדמי ואינה נותנת ייעוץ השקעות או שיווק השקעות כהגדרתם בחוק.
- הבהרה קבועה בממשק ובכל הערכת AI: "המידע וההערכות במערכת נוצרו אוטומטית לצורכי המחשה ואינם מהווים ייעוץ השקעות, שיווק השקעות או תחליף לייעוץ המותאם לנתונים ולצרכים של כל אדם."
- תנאי שימוש קצרים שהמשתמש מאשר בהרשמה.
- רישיון סוכן אינו מאומת מול רשות שוק ההון ומסומן כ"לא מאומת".
