## 13.4 תרחישי E2E (הדגמה)

1. **מסלול משקיע מלא**: הרשמה → שאלון → יעד דירה → הגשה → המתנה להערכה → צפייה בהמלצה.
2. **מסלול סוכן מלא**: התחברות → ליד חדש → Claim → אישור הערכה → שליחת הצעה.
3. **סגירת מעגל**: המשקיע מקבל את ההצעה → הסטטוס `ACCEPTED` בשני הדשבורדים → מונה "התקבלו" עולה בגרף המוצרים.
4. **סוכן מעלה מסמך** → סטטוס מוטמע → המסמך מופיע כמקור בהערכה הבאה.
5. **חיפוש והשוואה**: סינון לפי סיכון ודמי ניהול → בחירת 3 → מסך השוואה → מסך פרטים.
