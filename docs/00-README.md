# GoalVest – מסמכי אפיון (SDAD)

> פלטפורמה חכמה להשקעות מבוססות-מטרות, המחברת בין משקיעים פרטיים לסוכנים וגופים פיננסיים.
> השם GoalVest הוא שם עבודה וניתן לשינוי.

| פרט | ערך |
|---|---|
| קורס | הנדסת תוכנה בעידן AI – פרויקט סיום, סמסטר אלול תשפ"ו |
| מוסד | המרכז האקדמי לב |
| צוות | חדוה סבג, איילת סורובסקי (זוג – מסלול מבחר) |
| מתודולוגיה | Specification-Driven Application Development (SDAD) |
| גרסת מסמך | 1.0 – טיוטה לאישור הצוות |
| תאריך | אוקטובר 2026 |

## מטרת סט המסמכים

הפיתוח כולו מונחה מסמכים: סוכן הקוד (Claude Code / Cursor / Copilot) מקבל את המסמכים האלה כהקשר, ומפתח פיצ'ר שלם (Feature) בכל פעם – מהאירוע במסד הנתונים ועד המסך באנגולר – לפי הדרישות, הארכיטקטורה, הבדיקות והכללים המוגדרים כאן.

## החלטות שהתקבלו (מתוך שאלות האפיון)

| נושא | החלטה |
|---|---|
| צד לקוח | Angular + TypeScript |
| שרת אפליקציה | Flask (Python) |
| מסד נתונים | Somee.com (MS SQL Server בענן) עם Event Sourcing |
| מסד נתונים וקטורי | ChromaDB |
| מודל שפה | Ollama + Docker (מקומי) |
| מקור נתונים | שילוב: מניות מ-yfinance, קרנות ופוליסות מ-seed המבוסס על גמל-נט, ומוצרים שהסוכנים מזינים |
| שפת ממשק | עברית, RTL |
| פורמט אפיון | סט קבצי MD ל-Repo + מסמך Word מאוחד |

## מוסכמות

- מזהי דרישות: `FR-xx` פונקציונלית, `NFR-xx` לא-פונקציונלית, `US-xx` סיפור משתמש, `TC-xx` מקרה בדיקה.
- רמת עדיפות לפי MoSCoW: **Must** / **Should** / **Could** / **Won't (בגרסה זו)**.
- מונחים פיננסיים בעברית, מונחים טכניים באנגלית.

## מילון מונחים

| מונח | הסבר |
|---|---|
| משקיע | משתמש פרטי שמגדיר יעדים ומגיש בקשת השקעה |
| סוכן | נציג חברת ביטוח, בית השקעות או יועץ פיננסי מורשה |
| יעד (Goal) | מטרה פיננסית: דירה, פרישה, רכב, לימודים, קרן חירום |
| בקשת השקעה | הרשומה המרכזית שעוברת הערכת AI ואחר כך מגיעה לסוכנים כליד |
| ליד | בקשת השקעה שעברה הערכה וזמינה לסוכנים |
| מוצר / מסלול | מנייה, תעודת סל, קרן השתלמות, קופת גמל להשקעה או פוליסת חיסכון, במסלול השקעה מסוים |
| הערכת AI | פלט הסוכן: ציון התאמה, תמהיל מומלץ, נימוק ומקורות |
| אירוע (Event) | עובדה בלתי ניתנת לשינוי שנשמרת ב-Event Store |
| Projection / Read Model | טבלת קריאה שנבנית מהאירועים לטובת שאילתות |
